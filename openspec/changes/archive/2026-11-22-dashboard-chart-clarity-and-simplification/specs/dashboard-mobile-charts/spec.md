## REMOVED Requirements

### Requirement: Top 10 Notebook Benchmark Runs
**Reason**: Duplicated Notebook/Mobile performance and efficiency chart cards are consolidated into the unified Hardware Benchmark charts to reduce vertical clutter.
**Migration**: Use the Device Category filter set to `Mobile / SBC` in the Hardware Benchmark tab (`hardware-category-filter` capability).

### Requirement: Top 10 Handheld Benchmark Runs
**Reason**: Duplicated Handheld performance and efficiency chart cards are consolidated into the unified Hardware Benchmark charts to reduce vertical clutter.
**Migration**: Use the Device Category filter set to `Handheld` in the Hardware Benchmark tab (`hardware-category-filter` capability).
